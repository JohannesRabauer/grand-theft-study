# Economy, progress and rewards

## Description

Kids earn, spend and collect, and can see what they have learned. The spec owns the capabilities; the game architecture spine owns the technical rules.

## Outcome

Kids earn, spend and collect, and can see what they have learned.

## Done when

1. All earn and spend paths work and persist.
2. XP, stickers, streaks, achievements and cosmetics award and persist.
3. The Lernbuch shows real per-subject progress.

## Boundaries

One capability area of the game, following the spec. Not other epics' areas; see the spec's non-goals.
