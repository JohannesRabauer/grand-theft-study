# Polish, platform and release readiness

## Description

The game is solid, localized and ready for kids on real devices. The spec owns the capabilities; the game architecture spine owns the technical rules.

## Outcome

The game is solid, localized and ready for kids on real devices.

## Done when

1. A scripted full day plays from waking to Zeugnis in solo and co-op without errors.
2. The language and tone review passes.
3. The cross-browser checklist passes and the real-phone protocol is ready.

## Boundaries

One capability area of the game, following the spec. Not other epics' areas; see the spec's non-goals.
