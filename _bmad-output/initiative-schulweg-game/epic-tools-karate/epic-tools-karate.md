# Tools and karate

## Description

Kids can use all three tools on objects and train karate to defend against bullies without anyone getting hurt. The spec owns the capabilities; the game architecture spine owns the technical rules.

## Outcome

Kids can use all three tools on objects and train karate to defend against bullies without anyone getting hurt.

## Done when

1. The throwing stick and the stick work on their targets and never affect people or animals.
2. Karate belts are trained in the dojo and persist in saves.
3. Block, dodge and Kiai make bullies stumble back and lower Ärger with no violence shown.

## Boundaries

One capability area of the game, following the spec. Not other epics' areas; see the spec's non-goals.
