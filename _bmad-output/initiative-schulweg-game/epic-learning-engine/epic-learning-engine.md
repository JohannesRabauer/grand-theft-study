# Learning engine and Klasse 3 content

## Description

Kids get adaptive, bilingual Klasse 3 questions that repeat wrong answers and are always answered kindly. The spec owns the capabilities; the game architecture spine owns the technical rules.

## Outcome

Kids get adaptive, bilingual Klasse 3 questions that repeat wrong answers and are always answered kindly.

## Done when

1. next/answer/due work against saved per-topic stats and converge simulated learners toward 75–85% correct.
2. Klasse 3 question content for Mathe, Deutsch, Englisch, Sachkunde and Science exists in German and English and passes the content check.
3. The grades module maps results to German grades and averages.

## Boundaries

One capability area of the game, following the spec. Not other epics' areas; see the spec's non-goals.
